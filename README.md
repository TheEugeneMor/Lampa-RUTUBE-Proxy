# Lampa RUTUBE Proxy

Локальный прокси-плагин для Lampa, который помогает искать и смотреть видео с RUTUBE.

Автор: Eugene Pchelnikov. Связь в Telegram: [@eugenemor](https://t.me/eugenemor).

## Что это такое

RUTUBE сейчас содержит много фильмов, сериалов, передач и другого видео, причем часто в хорошем качестве. Этот плагин нужен, чтобы удобнее смотреть такой контент прямо в Lampa, без ручного поиска ссылок и лишних переключений между приложениями.

Иногда Lampa не может напрямую получить поток RUTUBE. Этот проект поднимает маленький веб-сервер на вашем компьютере. Lampa подключается к нему как к обычному плагину, а уже этот сервер ищет видео, получает HLS-ссылку и отдает ее обратно в Lampa.

Проще говоря:

1. Вы запускаете этот проект на компьютере.
2. Он показывает ссылку вида `http://192.168.x.x:8787/rt.js`.
3. Вы добавляете эту ссылку в Lampa.
4. Пока окно запускателя открыто, Lampa может ходить к RUTUBE через ваш компьютер.

Если телевизор или приставка находятся в той же домашней сети, обычно этого достаточно.

## Быстрый запуск

### Windows

Запустите файл:

```bat
launchers\windows\start.bat
```

Если PHP на компьютере не найден, запускатель сам скачает portable PHP в папку `launchers\windows\php`. Ничего отдельно искать и устанавливать обычно не нужно. Если системе не хватает Microsoft Visual C++ Redistributable x64, он тоже будет установлен автоматически.

После запуска в окне появятся адреса для Lampa, например:

```text
http://192.168.1.25:8787/rt.js
```

Добавьте этот адрес в настройках плагинов Lampa. Окно `start.bat` не закрывайте, пока смотрите видео.

### macOS

Запустите двойным кликом:

```text
launchers/macos/start.command
```

Или из Терминала:

```bash
./launchers/macos/start.command
```

Если PHP 8.1+ не найден, запускатель сам поставит его через Homebrew. Если Homebrew тоже не установлен, будет запущен официальный установщик Homebrew.

Первый запуск на macOS может занять несколько минут: система может попросить пароль, попросить нажать Enter и скачать Xcode Command Line Tools. Это нормально. Для автоматической установки Homebrew пользователь macOS должен быть администратором.

Если установка долго стоит на строке `Downloading Command Line Tools`, можно открыть во втором окне:

```bash
./launchers/macos/check-install-progress.command
```

Он покажет процессы установки, последние сообщения системного лога и размер папки `/Library/Updates`.

После запуска в окне появятся адреса для Lampa, например:

```text
http://192.168.1.25:8787/rt.js
```

Добавьте этот адрес в настройках плагинов Lampa. Окно `start.command` не закрывайте, пока смотрите видео.

## Какой адрес выбирать

Запускатель может показать несколько адресов. Чаще всего нужен тот, который начинается на:

- `192.168.`
- `10.`
- `172.`

Главное правило: устройство с Lampa должно видеть компьютер, на котором запущен сервер. Например, телевизор и компьютер должны быть в одной сети Wi-Fi или одной локальной сети.

## Как проверить, что сервер работает

После запуска откройте в браузере адрес:

```text
http://192.168.x.x:8787/
```

Вместо `192.168.x.x` подставьте IP, который показал запускатель.

Если страница открылась, сервер работает. Если Lampa не видит плагин, проверьте:

- компьютер и устройство с Lampa находятся в одной сети;
- выбран правильный IP-адрес;
- порт `8787` не заблокирован брандмауэром или настройками безопасности;
- окно запускателя все еще открыто.

## Как удалить установленное

### Windows

Чтобы удалить PHP, который скачал Windows-запускатель, запустите:

```bat
launchers\uninstallers\windows\uninstall-php.bat
```

Он удаляет только папку `launchers\windows\php`. Системный PHP и Microsoft Visual C++ Redistributable не трогаются.

### macOS

Чтобы удалить PHP, который поставил macOS-запускатель, запустите:

```bash
./launchers/uninstallers/macos/uninstall-php.command
```

Скрипт удаляет PHP только если этот проект сам установил его через Homebrew. Если PHP уже был на компьютере раньше, он останется на месте.

Чтобы удалить Homebrew, установленный macOS-запускателем, запустите:

```bash
./launchers/uninstallers/macos/uninstall-homebrew.command
```

Этот скрипт запускает официальный деинсталлятор Homebrew и перед удалением спрашивает подтверждение. Будьте внимательны: Homebrew может использоваться другими программами.

## Если нужен доступ извне

Если Lampa находится не в той же локальной сети, понадобится внешний IP или домен. Также нужно пробросить TCP-порт `8787` на роутере к компьютеру, где запущен сервер.

Пример адреса:

```text
http://your-domain.example:8787/rt.js
```

## Размещение на сервере или виртуалке

Папка `server` - это переносимая серверная часть. Ее можно положить на VPS, виртуалку или хостинг, где уже есть веб-сервер с PHP.

Требования:

- PHP 8.1+;
- Apache или nginx;
- желательно расширения PHP `curl` и `openssl`.

После размещения адрес для Lampa будет примерно таким:

```text
https://your-domain.example/rt.js
```

Подробности для Apache и nginx лежат в [server/README.md](server/README.md).

## Что где лежит

- `server/` - серверная часть плагина.
- `launchers/windows/start.bat` - запуск на Windows.
- `launchers/windows/setup-php.ps1` - установка portable PHP для Windows.
- `launchers/macos/start.command` - запуск на macOS.
- `launchers/macos/setup-php.command` - установка PHP через Homebrew на macOS.
- `launchers/macos/check-install-progress.command` - проверка, идет ли установка Homebrew или Xcode Command Line Tools.
- `launchers/uninstallers/` - скрипты удаления установленного PHP и Homebrew.
- `server/rt.js` - код плагина Lampa и явный файл для подключения.
- `server/proxy.php` - поиск RUTUBE через сервер.
- `server/stream.php` - получение HLS-ссылки.
- `server/hls.php` - прокси для HLS-плейлистов и сегментов.
